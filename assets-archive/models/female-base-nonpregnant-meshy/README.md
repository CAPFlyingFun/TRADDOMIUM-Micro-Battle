# Female base body, not pregnant (Meshy), kept for later

Joshua, 2026-10-29: "I had MESHY create a non-pregnant female base body... keep the current v2 model as the
default, and use this as newer reference to tweak the 0% shape... please save it for later as we can still try
later."

- `female-base-nonpregnant-meshy.glb`: the file Meshy exported (Blender glTF I/O 4.5), unchanged. One mesh,
  79,122 vertices, 140,046 triangles, rigged to Meshy's own 67-bone skeleton (`Bone_000`..`Bone_066`), bound in a
  T-pose, 1.70 m tall with her feet at y = 0, three JPEG textures, no morph targets and no animations.
- `reference-front.jpg`, `reference-side-right.jpg`, `reference-side-left.jpg`: Meshy's previews of it, as sent.

Not used by the game or the room. Sarah's approved body is still `sarah-v2-body.glb`; this one is a reference for
her 0% shape (the lower abdomen into the crotch, and a belly that is smooth all the way round at 0%), and a candidate
second body shape to try later with the same belly, breast and body sliders.
