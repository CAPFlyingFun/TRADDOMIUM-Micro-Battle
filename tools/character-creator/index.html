Character Creation and Clothing

Character Creator v0.4 · GLB/GLTF · paint, sculpt, export · not production-ready

Model and projects

Self-contained GLB works best. The app needs internet to load Three.js. If locally opened file stays blank, host it on localhost or GitHub Pages; use Demo body to test the 3D engine. Multi-material meshes are reduced to one editable material in this prototype. No files are sent to a server.

Editor tools

Use the visible 🎥 / 🎨 toggle above the viewport. 🎨 locks the camera and paints vertex colors directly (no UVs required). Texture paint remains available in this tool list. Sculpt and smooth edit geometry. Use Camera mode to orbit, zoom or pan.

Precision boundary / socks / waistline

Boundary is horizontal in 3D model space, not screen space. Region fill uses selected mesh UVs and triangle sampling, suitable for basic panels and socks. Garments are new offset geometry, not just a depth trick.

Garment controls

Offsets are in millimeters assuming model coordinates are meters. Use model scale control if the asset uses another unit.

Camera mode · drag to orbit · pinch to zoom
Demo ready
Select a tool and click the model. Drag background to orbit.

Meshes / layers

Select the body mesh before painting or defining a garment. Click the model to select a mesh in inspect mode.

Material controls

Texture upload replaces the selected mesh's paint base. Paint and filled regions are stored with the project.

Viewing

Scroll / pinch to zoom. Two-finger drag pans. Click a mesh in orbit mode to select it.

File compatibility

JSON stores editor state, brush textures, sculpted vertex positions, garment masks, camera and project metadata. Exported GLB captures actual visible geometry/materials for game integration. The JSON is a design recipe, not an automatic database upload.

Three.js modules load from jsDelivr. Internet is required to launch the standalone HTML. Your model processing stays in your browser.
